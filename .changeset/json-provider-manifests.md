All 16 providers (including B1.Church and FreeShow) are now pure JSON config manifests run by fixed shared code (`ManifestProvider`, `OAuthHelper`, `DeviceFlowHelper`, `FormLoginHelper`, `TokenHelper`, `NetworkDiscoveryHelper`, `PlanHelper`, and the shared transformation library). Adds offline-first launch sync (`syncProviders`, `hydrateCachedProviders`, `clearProviderCache`, `createMemoryStorage`, `onProvidersChanged`) with ETag and SHA-256 incremental updates so new providers published to a web server appear automatically without republishing apps while continuing to work offline from the last downloaded copy. Also adds `loadProviderFromUrl`, `registerProviderFromConfig`, `unregisterProvider`, `loadProviderIndex`, `setMdnsScanner`, `resolveMdnsServices`, declarative `networkDiscovery`, `form_login`, JSON token exchange, per-instance manifest `state`, structured manifest `functions`, inline/remote `datasets`, and `yarn export:manifests`.
